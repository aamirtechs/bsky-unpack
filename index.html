bsky-unpack

Turn a Bluesky account export (.car file) into a readable local archive: posts as markdown and JSON.

Press Run to see the report.

The Python CLI reads the binary .car file directly. This page carries the same bytes as base64 so the identical CBOR and CAR parsing logic can run on them in your browser.
